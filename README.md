# ASL Detector

Real-time ASL sign detector built with Python, OpenCV, and MediaPipe.

## Features
- Webcam hand tracking
- ASL gesture recognition
- Real-time OpenCV display
- Detects:
  - A
  - B
  - C
  - D
  - V
  - I LOVE YOU

## Tech Stack
- Python
- OpenCV
- MediaPipe

## Run

```bash
python3 asl_detector.py
